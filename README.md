# UCSB Course Grades SQL Project

## Goal
Analyze UCSB course grades using SQLite to summarize enrollment and grade distributions.

## Code
- [ucsb-grades.py](ucsb-grades.py)

## Descriptions
This project demonstrates basic database operations using SQLite in Python. It includes creating tables, inserting sample data, and running SQL queries to display grades and count student enrollment per course. 

## Technology
- Python, SQLite

## Skills
- SQL Queries (SELECT, WHERE, GROUP BY, ORDER BY), Database Creation, Data Analysis

## Results
Displayed all grades, queried specific courses, counted students per course, and sorted courses by enrollment.
